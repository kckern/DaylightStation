Renderer
The phosphor mask is drawn in output pixels, so this is both the look control and the main perf lever. 1.0 = CSS pixels; on a 4K panel try 2.0 for a true 1:1 mask.
Pre-filter — before the CRT
A separable gaussian run on the source at its own resolution, so the radius is in source pixels. It takes the hard edges off blocking and DCT artifacts before the CRT resamples, rather than smearing the phosphor mask the way a blur applied after the shader would. 0 bypasses both passes entirely.
