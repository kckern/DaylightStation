# Agenda module

Agenda owns weekly series and plans, their participant bindings, projections, launch references and durable source ledger. Its browser Admin editor edits drafts; the TV host presents dated menus and delegates participant-aware actions to the shared launch host. The shared content catalog owns consumer discovery and orchestration; individual consumers own activity setup and execution.

See the [household Agenda reference](../../../__docs/reference/household/agenda.md), [participant launch contract](../../../__capabilities/content-catalog/docs/participant-launch.md), and [migration runbook](../../../__docs/runbooks/agenda-migration.md).
